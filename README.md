# Toss & Toast — Premium React + TypeScript Demo

Sales-demo concept website for Toss & Toast, Jorhat, Assam, built for Novariyan.

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## GitHub Pages
The Vite base is already `./`, so the built site works from a project repository Pages URL.

1. Create a GitHub repository.
2. Push this project.
3. Run `npm install && npm run build`.
4. Deploy the `dist` folder with GitHub Pages (or enable Pages through GitHub Actions).
5. Before a client launch, replace concept imagery, verify menu/prices, address, phone, hours and ordering links with the café's confirmed details.

## Animation
Uses Framer Motion for restrained premium transitions: cinematic hero entrance, scroll reveals, staggered menu cards, image hover movement, active menu transitions, mobile navigation and subtle floating accents.
